# 知光项目 - 代码结构分类清单

> 后端源码根：`zhiguang_be/src/main/java/com/tongji`
> 生成范围：常量类 / 枚举类 / 请求 DTO / 响应 DTO / Controller 层 / Service 层 / 工具类 / 配置类
> 说明：路径均相对包根 `com.tongji`；DTO 大量使用 Java 21 `record`，Controller/Service 分层遵循「Controller 只做参数与身份解析，Service 承担业务」的纪律；工具类统一 `final` + `private` 构造器；配置类按业务模块就近落位（`模块/config`），全局基础设施集中在 `com.tongji.config`。

## 五、Controller 层

统一前缀 `/api/v1/*`，全部标注 `@RestController`，鉴权通过 Spring Security Resource Server 注入 `@AuthenticationPrincipal Jwt`，再由 [`JwtService#extractUserId`](../src/main/java/com/tongji/auth/token/JwtService.java) 解析出 `uid`。异常统一由 [`common.web.GlobalExceptionHandler`](../src/main/java/com/tongji/common/web/GlobalExceptionHandler.java) 转为 `{code, message}`。

### 5.1 [`auth.api.AuthController`](../src/main/java/com/tongji/auth/api/AuthController.java) — `/api/v1/auth`
| 方法 | 路径 | 入参 | 返回 |
| --- | --- | --- | --- |
| POST | `/send-code` | `SendCodeRequest` | `SendCodeResponse` |
| POST | `/register` | `RegisterRequest` + `HttpServletRequest` | `AuthResponse` |
| POST | `/login` | `LoginRequest` + `HttpServletRequest` | `AuthResponse` |
| POST | `/token/refresh` | `TokenRefreshRequest` | `TokenResponse` |
| POST | `/logout` | `LogoutRequest` | `204 No Content` |
| POST | `/password/reset` | `PasswordResetRequest` | `204 No Content` |
| GET | `/me` | `Jwt` | `AuthUserResponse` |

私有工具：`resolveClient(...)`、`extractClientIp(...)`（识别 `X-Forwarded-For`、`X-Real-IP`）。
